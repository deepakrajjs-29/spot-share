## 🎯 <span>Quick Overview</span>

<p align="justify">
<b>SNSECT’27</b> (International Conference on Sustainable and Novel Solutions in Electronics and Communication Technologies) is a premier academic gathering organized by the <b>Department of ECE, SNS College of Technology, Coimbatore</b>. The platform brings together global scientists, researchers, and academicians to deliberate on breakthrough innovations in sustainable hardware, green communication, VLSI, and intelligent IoT systems.
</p>

<div align="center">

| 📍 **Venue** | 📅 **Conference Dates** | 📚 **Proceedings Indexing** |
| :---: | :---: | :---: |
| **SNS College of Technology**, Coimbatore | **March 11 – 12, 2027** | **Springer LNEE (Scopus Indexed)** |

</div>

## 🚀 <span>Getting Started Locally</span>

<details>
<summary><b>💻 Click to view step-by-step setup guide</b></summary>

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/deepakrajjs-29/SNSCT-27.git
cd SNSCT-27
```

### 2️⃣ Install Dependencies
```bash
npm install
```

### 3️⃣ Launch Development Server
```bash
npm run dev
```
> Navigate to `http://localhost:5173` to explore the live application.

### 4️⃣ Production Build
```bash
npm run build
npm run preview
```

</details>
